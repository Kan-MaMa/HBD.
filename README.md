# 🎁 เว็บไซต์แฮปปี้เบิร์ดเดย์สายปั่น (Troll HBD Gift Box Web)

เว็บวันเกิดแนวเซอร์ไพรส์กวนๆ แบบคลีน 100%:
1. **หน้าแรก**: ขาวสะอาด โล่ง สบายตา มีเพียงกล่องของขวัญ 3 มิติดุ๊กดิ๊กอยู่ตรงกลาง ไม่มีปุ่มเครื่องมือใดๆ มากวนตา
2. **เมื่อกดเปิดกล่อง**:
   - 💥 ฝากล่องเปิดกระเด็นขึ้นฟ้า พร้อมเอฟเฟกระเบิดเสียงดังสนั่น + หน้าจอสั่น (Screen Shake)
   - 🎆 ประทัดและ Confetti พุ่งกระจายเต็มจอ พร้อมป้าย Comic "BOOM! 💥"
   - 🤪 **รูปเจ้าของวันเกิดทั้ง 4 รูป** พุ่งกระจายออกจากใจกลางกล่อง บินเด้งชนขอบจอไปมาแบบ DVD Screensaver
   - 🎶 ดนตรีวันเกิด 8-Bit จังหวะตื๊ดๆ ชวนหัวเราะ
   - 🔤 ข้อความวันเกิดสายฮา วิ่งกระพริบเปลี่ยนสีรุ้ง
   - 👆 คลิกตรงไหนบนจอก็จะระเบิดเสกรูปเพื่อนเพิ่มออกมาได้เรื่อยๆ!
